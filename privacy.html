yt-upload privacy policy

Last updated: 12 October 2026

yt-upload is a personal command-line tool used only by its owner to upload videos to the owner's own YouTube channels.

Data the tool accesses

With the owner's consent, the tool uses the YouTube Data API v3 to upload videos and to set their metadata, thumbnails, captions and playlists on the channel the owner selects. It does not read any other Google account data.

Data storage

The OAuth access and refresh tokens, and a record of each uploaded video's ID and metadata, are stored only in files on the owner's computer. No data is sent to, or stored on, any server operated by the developer.

Data sharing

No data is shared with, sold to, or transferred to any third party. Video files and metadata are sent only to YouTube through the YouTube API Services.

Removing access

Access can be revoked at any time on the Google Account permissions page. Deleting the token file on the owner's computer removes the stored credentials.

YouTube API Services

The tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's privacy policy is at policies.google.com/privacy.

Contact

Questions about this policy can be raised as an issue on this site's GitHub repository.
