yt-upload

yt-upload is a personal command-line tool that uploads videos from the owner's computer to the owner's own YouTube channels. It is not a public service and is not offered to other users.

What it does

  • Uploads a video file together with its title, description, tags, thumbnail and captions.
  • Sets the video's privacy status and scheduled publish time.
  • Adds the video to playlists on the same channel.

How it uses Google data

The tool uses the YouTube Data API v3 and asks for permission to upload and manage videos on the channel the owner selects. It runs entirely on the owner's computer. See the privacy policy for details.

yt-upload is built on the open-source youtubeuploader project and uses YouTube API Services.
